# s390x Test Tier — STD Index

## Overview

The `s390x` Playwright project validates CNV/KubeVirt UI behaviour specific to IBM Z.
UI filter/catalog tests can run in **mock mode** on any cluster. VM lifecycle tests require a real s390x cluster.

## Running

| Mode       | Env                                            | Command                                             |
| ---------- | ---------------------------------------------- | --------------------------------------------------- |
| Real s390x | `ARCH=s390x` (or console URL contains `s390x`) | `./playwright-runner.sh s390x`                      |
| Mock mode  | `S390X_MOCK_ENABLED=1`                         | `S390X_MOCK_ENABLED=1 ./playwright-runner.sh s390x` |

## Tags

| Tag      | Purpose                 |
| -------- | ----------------------- |
| `@s390x` | All s390x project tests |

## Specs

- `tests/s390x/catalog-s390x.spec.ts` — architecture filter + Windows absence (mockable)
- `tests/s390x/create-vm-s390x.spec.ts` — RHEL9 create + catalog filters (real cluster)
- `tests/s390x/vm-list-s390x.spec.ts` — list/template suffix (real cluster for create)

## Related accommodations (all projects)

- `EnvVariables.isS390x` / `getTemplateMetadataName` — `-s390x` template suffixes
- Catalog Windows filters/creates skip on s390x (release-4.21 parity)
- Empty default `CATALOG_DISK_HTTP_IMAGE_URL` on s390x (override via env)
